# User Flows

## Owner onboarding
Sign up → create school → configure session/terms → create classes/subjects → invite staff → import students → configure fees → dashboard.

## Student onboarding
Create/import student → assign guardian → enrollment → class assignment → active status.

## Teacher attendance
Login → My Classes → select class/date → mark statuses → submit → confirmation → parent notification job → intelligence update.

## Teacher results
My Classes → subject → assessment → enter scores → validation → calculate grades → submit → approval/publish workflow → report card data.

## Finance
Fee structure → assign to students/class → generate invoices → notify parent → parent opens checkout → provider payment → webhook → verify → record payment → update balance → receipt → notification.

## Action Center
Signal created → priority calculated → action recommended → owner assigned → review → approve/execute → result captured → action resolved.

## AI
User question → authentication/role check → intent → tool selection → permission check → tool execution → validated result → explanation with evidence → audit AI interaction.

## Parent
Login/secure link → select child → overview → fees/results/attendance → pay or respond → receipt/status.
