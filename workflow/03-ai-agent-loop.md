# AI Agent Loop

The coding agent must behave like a senior engineer:
- Never assume a missing dependency exists.
- Inspect before editing.
- Make small changes.
- Preserve working code.
- Test after each meaningful change.
- Fix root causes rather than masking errors.
- Never claim success without evidence.
- If a provider credential is unavailable, implement a truthful adapter/mock boundary and document the exact remaining setup; never fake production success.
- Keep PROJECT_STATUS.md and TASKS.md current.
