# Definition of Done

A phase is DONE only when:
- All phase tasks are complete or explicitly deferred with reason.
- Acceptance criteria pass.
- Relevant tests pass.
- Typecheck passes.
- Lint passes.
- Production build passes.
- No known blocking errors remain.
- UI has been inspected at desktop and mobile widths where relevant.
- Authorization and tenant isolation are verified for affected data.
- Documentation and status are updated.
- Next-phase dependencies are confirmed.
