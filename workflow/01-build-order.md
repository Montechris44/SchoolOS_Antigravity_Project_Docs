# Build Order

Follow the roadmap strictly. Do not build future-phase features early unless a documented dependency requires a small foundation change.

For every phase:
1. Read requirements.
2. Inspect current code.
3. Identify dependencies.
4. Plan smallest complete implementation.
5. Implement.
6. Run checks.
7. Inspect UI and behavior.
8. Fix all failures.
9. Verify acceptance criteria.
10. Update docs/status/tasks.
11. Create checkpoint.
12. Proceed only if checkpoint passes.
