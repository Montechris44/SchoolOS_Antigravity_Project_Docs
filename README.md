# SchoolOS

SchoolOS is an AI-powered operating system for Nigerian private schools.

## Product thesis
SchoolOS does not merely store school data. It turns school activity into decisions:
**Capture → Understand → Detect → Recommend → Act → Measure**

## Initial ICP
Private primary and secondary schools in Nigeria, approximately 100–1,500 students, with an owner/proprietor as the economic buyer.

## MVP
- Authentication and school/workspace setup
- Students, parents, teachers and classes
- Academic sessions and terms
- Attendance
- Assessments, results and report cards
- Fee structures, invoices, payments and receipts
- Parent communication
- Management dashboard
- Intelligence Engine
- Action Center
- AI Assistant
- Paystack payment integration
- WhatsApp/SMS-ready communication architecture

## Recommended stack
Next.js + TypeScript + Tailwind CSS + shadcn/ui + Supabase/PostgreSQL + Paystack + LLM API + WhatsApp/SMS provider.

## Build principle
Use a modular monolith. Build in phases. Do not advance a phase until its checkpoint passes.
